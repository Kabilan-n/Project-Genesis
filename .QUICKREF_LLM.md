# 🚀 LLM Provider Quick Reference

## Change Your LLM Provider in 30 Seconds

### Current Setup (Claude Haiku)
```env
LLM_PROVIDER=anthropic
LLM_MODEL=claude-haiku-4-5-20251001
ANTHROPIC_API_KEY=sk-ant-...
```
✅ **No changes needed** — just run `npm run start`

---

## Try Other Providers

### 🟢 Ollama (Local, Free)
```env
LLM_PROVIDER=ollama
LLM_MODEL=llama2
OLLAMA_BASE_URL=http://localhost:11434
```
**Setup:** `ollama pull llama2 && ollama serve`

### 🔵 OpenAI (GPT-4)
```env
LLM_PROVIDER=openai
LLM_MODEL=gpt-4o
OPENAI_API_KEY=sk-...
```
**Setup:** Get key from https://platform.openai.com/account/api-keys

### 🟡 HuggingFace
```env
LLM_PROVIDER=huggingface
LLM_MODEL=meta-llama/Llama-2-7b-chat-hf
HUGGINGFACE_API_KEY=hf_...
```
**Setup:** Get key from https://huggingface.co/settings/tokens

## Steps to Switch

1. **Edit `.env`:**
   ```bash
   nano .env  # or use your editor
   ```

2. **Set provider:**
   ```env
   LLM_PROVIDER=ollama  # or openai, huggingface, anthropic
   ```

3. **Run simulation:**
   ```bash
   npm run start
   ```

4. **Check logs:**
   ```
   [INFO] Using LLM Provider: ollama
   [INFO] Model: llama2
   ```

## Troubleshooting

| Problem | Solution |
|---------|----------|
| "Missing API key" | Set your API key in `.env` for the provider |
| "Connection refused" | For Ollama, run `ollama serve` in another terminal |
| "Model not found" | For Ollama, run `ollama pull <model>` |
| "Slow responses" | Switch to a smaller model or use Ollama locally |
