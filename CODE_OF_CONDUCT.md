# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**.

The full text is the authoritative source:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

A plain-text version is available at:
https://www.contributor-covenant.org/version/2/1/code_of_conduct.txt

## Scope

The Covenant applies to all project spaces — the repository, issue
tracker, PR reviews, and any official communication channels.

## Reporting

Concerns can be reported to the project maintainer via the email
configured on the repository owner's GitHub profile, or by opening a
private issue marked "conduct" if the platform supports it.

Reports are handled per the enforcement guidelines defined in the
Covenant.
